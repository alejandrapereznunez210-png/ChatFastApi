# ChatFastApi

## Descripción
Chat grupal desarrollado con FastAPI y WebSockets para enviar y recibir mensajes en tiempo real dentro de una red local

## Tecnologías
- Python
- FastAPI
- Uvicorn
- WebSockets
- HTML y JavaScript

## Instalación
Instalar las dependencias con:

pip install -r requirements.txt

## Ejecución
Iniciar el servidor con:

python -m uvicorn main:app --host 0.0.0.0 --port 8000

Después, abrir en el navegador:

http://127.0.0.1:8000

Para otros dispositivos, utilizar la dirección IP local del equipo servidor y el puerto 8000.
